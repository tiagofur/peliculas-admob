# 1. Introducción

La aplicación **Películas AdMob** es una plataforma cross-platform (Android, iOS, Web, Desktop) para explorar, gestionar y compartir contenido cinematográfico.

### Objetivos

- Proveer una experiencia de usuario fluida para buscar y descubrir películas.
- Integrar monetización adaptativa mediante AdMob y AdSense.
- Soportar funcionalidades avanzadas: gamificación, offline-first y sincronización en tiempo real.

### Características Principales

- Autenticación con Supabase.
- Listado y búsqueda de películas usando TMDB.
- Watchlist, favoritos y calificaciones.
- Logros y niveles.
- Sincronización multi-dispositivo y offline.
- Monetización móvil y web.
