# Archive Directory

This directory contains historical documentation that has been superseded by newer, consolidated guides but is preserved for reference purposes.

## Directory Structure

### `2025-09-audits/`

September 2025 audit reports and related documentation. These detailed audits have been consolidated into `docs/audits/2025-q4-summary.md` but are kept here for historical reference.

**Contents:**

- Daily audit reports from September 25-29, 2025
- Detailed issue tracking and resolution notes
- Performance analysis reports
- October 3, 2025 follow-up audit

### `legacy-fixes/`

Historical bug fixes, patches, and implementation notes from 2025. These documents capture the evolution of the codebase and solutions to past problems.

**Contents:**

- Google Auth implementation history (consolidated in `docs/guides/google-auth.md`)
- Supabase realtime sync fixes (consolidated in `docs/guides/supabase-realtime.md`)
- P0 critical fixes (consolidated in `docs/audits/p0-critical-fixes.md`)
- Debug reports and troubleshooting logs
- January-October 2025 dated fix reports
- Custom features and experimental implementations

### `opus/`

Opus-related documentation and specifications.

## When to Reference Archive

**Consult archived documentation when:**

- Debugging a recurring issue that was previously fixed
- Understanding the historical context of a design decision
- Looking for detailed step-by-step resolution of a past problem
- Researching similar issues that occurred in previous months
- Auditing code changes and their rationale

## Archive Policy

Documents are archived when:

1. Content has been consolidated into a comprehensive guide
2. Information is outdated but historically valuable
3. Detailed logs are superseded by summary reports
4. Files are dated and reference resolved issues

**Note:** All essential information from archived files has been preserved in the current documentation. These files are kept only for historical context and detailed reference.
